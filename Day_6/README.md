역기구학은 감쇠 최소제곱 기반의 수치적 방법으로 구현하였다. 현재 관절각에서 FK로 구한 손끝 위치와 목표 위치의 오차를 계산하고, 기하학적 야코비안 J를 이용해 Δq = Jᵀ(JJᵀ + λ²I)⁻¹e만큼 관절각을 갱신하는 과정을 오차가 허용 범위 이하가 될 때까지 반복한다. 감쇠 계수 λ는 특이점 근처에서 관절각이 급격히 변하는 것을 막기 위해 사용하였으며, 오차가 클수록 크게 설정하여 안정성과 수렴 속도를 함께 확보하였다.
