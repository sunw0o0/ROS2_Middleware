# 역기구학_ik

Qt로 만든 UI의 버튼으로 로봇팔 끝 목표 위치를 옮기면, 역기구학으로 관절각을 계산해 RViz에서 로봇팔이 따라 움직이도록 구현.

[Screencast from 2026-11-15 20-36-11.webm](https://github.com/user-attachments/assets/030ee6ac-5c6d-4e49-ac71-5e3353f2a2f7)

## 동작 흐름
버튼 클릭 → 손끝 목표 10 mm 이동 → IK로 관절 6개 각도 계산 → `/joint_states` 퍼블리시 → RViz에서 로봇팔 이동

- 좌표계는 로봇팔이 앞을 바라보는 방향을 +x로 설정하였다.
- 목표가 닿을 수 없는 위치이면 팔을 움직이지 않고 상태줄에 경고를 띄운다.

## 역기구학 방법
감쇠 최소제곱 기반의 수치적 방법으로 구현하였다.

1. 현재 관절각으로 FK를 계산해 손끝 위치를 구한다.
2. 목표 위치와의 오차 e를 구한다.
3. 야코비안 J로 오차를 줄이는 관절 회전량을 구한다.

   Δq = Jᵀ(JJᵀ + λ²I)⁻¹e

4. 관절각을 Δq만큼 갱신하고, 오차가 허용 범위(0.5 mm) 이하가 될 때까지 반복한다.

- 야코비안 J: 각 관절을 조금 돌렸을 때 손끝이 움직이는 방향과 크기를 나타내는 행렬
- 감쇠 계수 λ: 팔이 펴진 특이 자세에서 관절각이 급격히 커지는 것을 막는 값. 오차가 클수록 크게 설정하여 안정성과 수렴 속도를 함께 확보하였다.
- 그리퍼 방향 고정: 위치만 맞추면 손목 관절만 주로 움직여, 그리퍼 방향을 처음 자세로 고정하는 조건을 추가하였다. 그 결과 어깨와 팔꿈치를 포함한 팔 전체가 움직인다.

## UI 구성
| 항목 | 내용 |
|---|---|
| 앞/뒤, 오른쪽/왼쪽, 위/아래 | 손끝 목표를 x, y, z 방향으로 10 mm씩 이동  |
| 관절각 | joint1~6의 현재 각도 |
| T값 | 현재 손끝의 4×4 변환행렬 (왼쪽 3×3 = 방향, 오른쪽 위 3칸 = 위치 mm) |
| 상태줄 | 목표 좌표와 위치 오차 |
