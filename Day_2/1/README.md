#### 2. 예상
지연 100ms ± 20ms, 손실 5%를 걸면 결과가 어떻게 될까요?

1. mean은 대략 몇 ms가 될까?
   
   지연 100+20이다. 근데 데이터가 갔다가 오는 것도 고려해야하므로 2*(100+20)ms만큼 지연될 것 같다.

2. loss는 5%쯤 나올까, 더 많을까, 더 적을까?
   
   qos가 reliable이므로 5%일지는 모르겠지만 0%보다는 더 나올 것 같다.
   
3. p95는 평균과 비슷할까, 훨씬 클까?
   
   위에서 했을 때는 loss가 0%였기에 RTT값이 작게 나왔지만 loss가 0%가 아니라면 더 크게 나올 것 같다.

#### 3. 지연 100+20ms, 손실 5% 결과

결과를 보면 loss가 10%이므로 200개 중에서 20개는 데이터가 안보내진 것을 볼 수 있다. 또한 RTT가 407.1ms가 나왔고, 95%의 데이터는 1035.9ms안에 온 것을 볼 수 있다. 여기서 좀 이상한 점은 RTT 평균이 400이 넘게 나온 것이다. 사실 예상한 값은 2*(100+20)ms이므로 200~300ms가 나와야했다. 심지어 1035.9ms도 내 예상보다 너무 크게 나왔다.

#### 3-1. 결과 분석

1. loss

   나는 loss를 5%만 걸어주었지만 10%가 나온 이유는 loss도 갔다가 오는 두번 적용되기에 갔을 때 5%, 올 때 5%해서 10%라는 값이 나왔다. 근데 여기서 좀 이상한 점은 reliable로 데이터를 보내면 loss가 안나와야하는데 10%가 나온 것이다.

2. RTT

   실험 환경에서는 ping에서 pong으로 데이터가 갈 때 delay, pong에서 ping으로 데이터가 올 때 delay해서 200ms가 나와야하지만 평균이 400이 넘게 나왔다.
